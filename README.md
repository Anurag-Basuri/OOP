## How to use these notes

- **Encapsulation**: protect state and enforce valid changes.
- **Abstraction**: expose essential behavior and hide implementation details.
- **Inheritance**: build a child type from a parent type.
- **Polymorphism**: use one operation with different implementations.
- **Interfaces**: define capabilities or contracts.
- **`this` / `self`**: refer to the current object.
- **`super`**: reuse parent behavior.
- **Static members**: store type-level data or operations.

Each topic explains its own definition first. Related topics link to the
specialized guide instead of repeating the same examples.
